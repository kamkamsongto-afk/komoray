## วิธีที่ทดสอบ

สั่งครั้งเดียว → Modal หลายเครื่องแบ่งกันตัดไฟล์ตัวอย่าง (`proxy.mp4`) ครบทุกเฟรมด้วย Google selfie segmenter (โมเดลเดียวกับในเบราว์เซอร์) → แต่ละเครื่องทำ `matte.mp4` และ `proxy-cutout.mp4` ท่อนของตัวเอง ด้วยค่าเดียวกับ `finish_local` → ต่อไฟล์และอัปขึ้น R2 ของ staging

สคริปต์: [`full_path.py`](full_path.py) (แอปทดลองแยกต่างหาก ไม่ได้ deploy) รับไฟล์ JSON ของลิงก์เซ็น `proxy`, `source`, `matte_put`, `preview_put`

```sh
python -m modal run docs/trials/cutout-server/full_path.py --links-file links.json --limit 9000 --label five --most 4
```

เครื่องละ 4 คอร์ 3 GB · `scaledown_window=2` · เปิดแอปใหม่ทุกรอบ (เครื่องเย็น)

## คุณภาพ (2 นาทีแรกของคลิปพูดหน้ากล้อง 1 คลิป)

เทียบกับการตัดในเบราว์เซอร์แบบทุกเฟรม วัดเป็นสัดส่วนพื้นที่ตัวคนที่ต่างกัน

| แบบ | เฉลี่ย | เฟรมที่ต่างเกิน 2% |
|---|---|---|
| บนเซิร์ฟเวอร์ | 0.10% | 0.03% (1 จาก 3,600) |
| ในเบราว์เซอร์ เว้น 2 เฟรม | 0.09% | 0.22% |

จังหวะเฟรมตรงกันพอดี (ความต่างน้อยสุดเมื่อเลื่อน 0 เฟรม)

## ค่าใช้จ่าย

- บิลจริง (`modal billing report`) ของ 7 รอบในตาราง ≈ 0.197 ดอลลาร์ (72,256 เฟรม) · รอบละประมาณ 0.005–0.05 · ราว 1 ใน 4 เป็น network egress
- สูตร "เวลาเครื่องทำงาน × ราคาประกาศ" ต่ำกว่าบิลจริง 3–8 เท่า (ไม่รวมเวลาเปิดเครื่องและการส่งไฟล์) **ห้ามใช้สูตรนี้ประเมินราคา**
- 1,000 คลิป (5 นาที): แบบเซิร์ฟเวอร์ราว 20–40 ดอลลาร์ แบบเดิมราว 15 ดอลลาร์

## ยังไม่ได้ทดสอบ

ใช้ไฟล์จากเซิร์ฟเวอร์ใน AI studio และ `Make video` จริง · หลายคนใช้พร้อมกัน · ปรับจำนวน/ขนาดเครื่องเพื่อลดค่าใช้จ่าย · คลิปที่ขยับตัวเร็วหรือหลายคนในภาพ
