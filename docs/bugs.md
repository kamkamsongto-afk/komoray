# ตารางกันบั๊กเก่ากลับมา

ย้ายมาจาก `AGENTS.md` ข้อ 5 เมื่อ 13 พ.ย. 2026 (โยชิอนุมัติ) เพราะ Codex อ่าน `AGENTS.md` ได้แค่ 32 KiB แรก ไฟล์นี้ไม่มีเพดานนั้น
แต่ไม่ถูกโหลดเอง: **agent ทุกตัวต้องเปิดอ่านไฟล์นี้ทั้งไฟล์ก่อนแก้โค้ด** (กติกาอยู่ใน `AGENTS.md` ข้อ 3 และ 5)
